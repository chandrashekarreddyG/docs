How it works (summary)

Ingestion

Two paths: user-submitted deals go through AI moderation (URL safe, duplicate detect, price sanity with MRP-inflation detector, OpenAI gpt-4o-mini). Scraped deals (Amazon/Flipkart/Myntra) enter PENDING_REVIEW via GitHub Actions and become live only after admin approval.

Ranking

Community votes (UP / DOWN) feed a decaying hot-score. Status votes (WORKING / EXPIRED) expire stale deals when expired ≥ 10 and ≥ 2× working. Deal posters earn reputation (+1 / -1).

Alerts

Filters (category, store, min discount %, keyword) trigger every 30 min. Matching notifications batch at 100 and go out via Expo Push to mobile devices.

SEO / surfaces

Sustainable SEO comes from live DB pages: /deals/[slug], /store/[slug], /category/[slug], intent pages (/under/[price], /expiring-today, /sale/[event]). No templated buying guides.

Critical rules (CLAUDE.md): No fabricated SEO pages; canonical domain is snatchpicks.com; sitemap/footer are generated; git commands must use GIT_CONFIG_GLOBAL=/dev/null; never pnpm install; never prisma db push; mobile is standalone (cd apps/mobile && npm install).
